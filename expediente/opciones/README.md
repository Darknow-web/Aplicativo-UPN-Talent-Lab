# Fichas de ideas evaluadas

Las crea `explorador-de-oportunidades` en la Fase 2 de `/explorar`; el Director actualiza el campo **Estado** en las fases 3 y 4 (candidata / lista corta / finalista / elegida / descartada en Fase N — motivo).
