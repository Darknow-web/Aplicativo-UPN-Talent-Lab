# Informes de especialistas

Un archivo por especialista y por fecha: `AAAA-MM-DD-<rol>.md` (ej.: `2026-11-03-analista-mercado.md`). Nunca se sobreescribe un informe anterior; un re-análisis genera un archivo nuevo con la fecha real.

Formato obligatorio: resumen (máx. 5 líneas) → hallazgos con etiquetas de evidencia → recomendaciones (qué, por qué, costo, métrica) → riesgos → preguntas abiertas para los socios. Máximo 2 páginas.
